# Frases de Pipo

Una frase por línea. Las líneas que empiezan con `#` y las vacías se ignoran.
Después de editar, GitHub vuelve a publicar la página solo (en 1 o 2 minutos).

Reglas para que todas sirvan con cualquier persona:
- Que sirvan igual para hombres y mujeres: «Eres una persona increíble», no «Eres increíble y valioso».
- Cortas (hasta unos 70 caracteres), para que se lean en el globo.
- Amables, sin tono romántico ni preguntas personales.

| Archivo | Cuándo sale |
|---|---|
| `animo.txt`, `carino.txt`, `humor.txt` | En cualquier momento (son la mayoría). |
| `manana.txt`, `tarde.txt`, `noche.txt` | Según la hora del celular (5–12, 12–19, 19–5). |
| `lunes.txt`, `viernes.txt`, `finde.txt` | Esos días. |
| `regreso.txt` | Al volver a abrir la página (de la segunda visita en adelante). |
| `cocacolita.txt` | A veces, cuando Pipo ofrece la lata (la primera vez siempre dice «¿Quieres una cocacolita? 🥤»). |
